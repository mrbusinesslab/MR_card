iPhone／iPad使用 Safari 瀏覽器
  1. 使用 Safari 開啟確認目前已進入自己的名片頁。
  2. 點選「分享」按下方工具列的方框向上箭頭。
  3. 選擇「加入主畫面」確認名稱後，點右上角「新增」。
Android使用 Chrome 瀏覽器
  1. 使用 Chrome 開啟確認目前已進入自己的名片頁。
  2. 點選右上角「⋮」開啟 Chrome 瀏覽器選單。
  3. 選擇「加到主畫面」部分手機會顯示「安裝應用程式」。
